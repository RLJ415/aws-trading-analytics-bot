# AWS Trading Analytics Bot

A live, serverless stock market analytics application built on AWS.

This project automatically collects historical stock market data, analyzes trading opportunities with a custom Python strategy, stores data and chart artifacts in Amazon S3, exposes current results through a REST API, and displays those results in a live AWS-hosted web dashboard.

The project was built to demonstrate practical skills in:

* AWS Cloud Engineering
* Serverless Architecture
* Data Engineering
* Python Automation
* REST APIs
* SQL Analytics
* Containerization
* IAM Security
* Cloud Monitoring
* Frontend Data Integration

# AWS Services Used

* **Amazon S3** — stores raw stock data, technical charts, and dashboard results
* **AWS IAM** — controls least-privilege access between AWS resources
* **AWS Lambda** — runs the trading bot and dashboard API
* **Amazon ECR** — stores the Docker container image used by the production trading Lambda
* **Amazon EventBridge Scheduler** — invokes the trading bot four times each weekday during market hours
* **Amazon API Gateway** — exposes the dashboard REST API
* **Amazon SNS** — sends bot completion notifications
* **Amazon CloudWatch** — stores Lambda logs, enforces log retention, supports troubleshooting, and alarms on Scheduler target failures
* **AWS Glue Data Catalog** — catalogs market data stored in Amazon S3
* **Amazon Athena** — performs serverless SQL queries against S3 data
* **AWS Amplify Hosting** — hosts the live web dashboard
* **AWS CLI** — manages and validates AWS resources from the command line

# Trading Strategy

The bot uses a custom Hybrid Trading Strategy combining technical indicators and price structure.

The strategy evaluates:

* Relative Strength Index (RSI)
* Support zones
* Resistance zones
* Current price location
* Bounce confirmation
* Rejection confirmation
* Minimum four-touch support/resistance confirmation
* Reward-to-risk ratio
* Confidence score

The strategy can generate:

* BUY
* HOLD
* SELL

Each stock analysis also includes reasoning describing why a trade setup was or was not confirmed.

## CloudWatch Reliability Alarm

```text
PJ3-Scheduler-Target-Error
```

Alarm configuration:

```text
Namespace: AWS/Scheduler
Metric: TargetErrorCount
ScheduleGroup: default
Statistic: Sum
Period: 5 minutes
Threshold: >= 1
SNS topic: trading-alerts
```

Missing data is treated as not breaching so the alarm remains `OK` when no Scheduler target errors are occurring.

A post-launch Scheduler failure was traced to missing `lambda:InvokeFunction` permission for `trading-bot-runner-container`. After correcting the IAM permission, a one-time Scheduler test verified:

```text
EventBridge Scheduler
→ trading-bot-runner-container
→ S3 dashboard update
→ SNS publish
→ email delivery
```

# Cloud Security

The project keeps the primary market-data S3 bucket private.

The public dashboard does not directly expose the S3 bucket.

Instead:

1. The browser requests trading results through Amazon API Gateway.
2. API Gateway invokes `trading-dashboard-api`.
3. Lambda reads the private dashboard JSON from Amazon S3.
4. Lambda generates temporary presigned URLs for chart images.
5. The browser uses those temporary URLs to display the private charts.

IAM policies restrict each Lambda function to the AWS resources it requires.

# Data Analytics

Market data stored in Amazon S3 is cataloged through AWS Glue.

Amazon Athena can query that data directly with SQL without requiring a traditional database server.

Example verified query:

```sql
SELECT *
FROM stock_prices
LIMIT 5;
```

This adds a serverless data-analysis layer to the trading application in addition to the real-time strategy engine.

# Known Issue

The watchlist contains 100 stocks, but the latest verified production run produced 99 dashboard results.

The missing ticker was:

```text
MMC
```

During that run, Yahoo Finance returned no market data for MMC.

The collector safely skipped the empty result rather than failing the entire trading pipeline.

This is considered a post-launch resiliency improvement and does not prevent the application from operating.
